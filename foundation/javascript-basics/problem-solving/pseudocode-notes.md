# Pseudocode

**Source:** [Built In — Pseudocode: What It Is and How to Write It](https://builtin.com/data-science/pseudocode)

## What Is Pseudocode?

Pseudocode is a **plain-English plan for an algorithm**.

It describes the logic without worrying about JavaScript, Python, or another language's syntax.

> “Pseudocode merely acts as a master plan for writing code.”

## Why Use It?

- Focus on **logic**, not syntax.
- Break complex problems into clear steps.
- Find design mistakes before coding.
- Make implementation easier.
- Communicate ideas clearly.

## How to Write Good Pseudocode

- One statement per line.
- Use indentation for hierarchy.
- Keep it simple and readable.
- Stay independent of programming languages.
- Use problem-domain language.
- Clearly show conditions and loops.

### Example

```text
IF order price >= 50
    Apply discount
    Display "Discount applied!"
ELSE
    Do not apply discount
    Display "Add more items for discount!"
ENDIF
```

## Main Constructs

```text
SEQUENCE       → steps in order
IF-THEN-ELSE   → decisions
WHILE          → loop while condition is true
REPEAT-UNTIL   → loop until condition is true
FOR            → repeated iteration
CASE           → multiple choices
```

## Important Lesson

Pseudocode is **not writing the same code twice**.

For simple problems, it may feel unnecessary. For larger problems, it helps you think through the algorithm **before syntax gets in the way**.

> “Why write code twice?”

The answer: **you aren't writing code twice—you are designing first, then implementing.**
