Task 9 – Check the Login

Importance: ★★★

Write the code which asks for a login using prompt().

Requirements

  • If the visitor enters "Admin", then ask for a password.
  • If the input is an empty string or the user presses Esc, show "Canceled".
  • If the visitor enters any other login, show "I don't know you".

Password Check

  • If the password is "TheMaster", show "Welcome!".
  • If another password is entered, show "Wrong password".
  • If the password is empty or the prompt is canceled, show "Canceled".

Instructions

  • Use nested if statements.
  • Keep the code clean and readable.
  • Do not use other control structures.
Hint:

An empty input in prompt() returns "" (empty string).
Pressing Esc returns null.
