Foundations – How Does the Web Work?

Lesson Overview

Before building websites, it's important to understand what happens behind the scenes when someone visits a website. This lesson explains how computers communicate over the Internet and how a webpage reaches your browser.

Key Concepts

1. What is the Internet?

  • A global network connecting millions of computers.
  • Allows devices to exchange information.
  • Uses standard communication protocols (TCP/IP).

2. What is the Web?

  • The World Wide Web is a service that runs on the Internet.
  • It consists of websites and webpages connected through links.
  • The Internet is the infrastructure; the Web is one of its services.

3. Client & Server

  • Client: The user's device (browser).
  • Server: A computer that stores website files.
  • The client requests data, and the server responds.

4. IP Address

  • Every device on the Internet has a unique address.
  • Used to locate and communicate with other devices.

5. DNS (Domain Name System)

  • Converts domain names into IP addresses.
  • Acts like the Internet's phonebook.
  • Example: google.com → IP Address.

6. Packets

  • Data is divided into small packets.
  • Packets travel independently across the Internet.
  • They are reassembled when they reach the destination.

7. Browser

  • Requests webpages from servers.
  • Interprets HTML, CSS, and JavaScript.
  • Displays the website to users.

8. Search Engine

  • Helps users find websites.
  • Indexes billions of webpages.
  • Google, Bing, DuckDuckGo are search engines.

What Happens When You Visit a Website?

  1. You type google.com into your browser.
  2. The browser asks a DNS server for Google's IP address.
  3. DNS returns the correct IP address.
  4. Your browser sends an HTTP/HTTPS request to Google's server.
  5. The server processes the request.
  6. The server sends HTML, CSS, JavaScript, images, and other files.
  7. Your browser downloads and renders the webpage.
  8. The website appears on your screen.

Important Terms

Term Description
Internet Global network of computers.
Web Collection of websites on the Internet.
Client User's browser or device requesting data.
Server Computer hosting website files.
IP Address Unique address of a device.
DNS Converts domain names into IP addresses.
Packet Small piece of transmitted data.
Browser Software used to access websites.
Search Engine Finds websites on the Internet.

Key Takeaway

Whenever you open a website, your browser doesn't magically know where it is. It asks DNS for the server's address, sends a request over the Internet, receives the website files in packets, and renders them into the webpage you see.
