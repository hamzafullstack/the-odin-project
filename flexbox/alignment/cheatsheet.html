🎯 Flexbox Cheat Sheet

1. Parent (Flex Container) Properties

  • display: flex; → Turns an element into a flex container.
  • flex-direction → Sets the main axis direction.
    • row (default)
    • row-reverse
    • column
    • column-reverse
  • flex-wrap → Controls wrapping.
    • nowrap (default)
    • wrap
    • wrap-reverse
  • flex-flow → Shorthand: 
    flex-flow: row wrap;
  • justify-content → Aligns items on the main axis.
    • flex-start
    • flex-end
    • center
    • space-between
    • space-around
    • space-evenly
  • align-items → Aligns items on the cross axis.
    • stretch (default)
    • flex-start
    • flex-end
    • center
    • baseline
  • align-content → Aligns multiple rows/columns (only works with wrapping).
    • stretch
    • center
    • space-between
    • space-around
    • space-evenly
  • gap → Space between flex items.
  • row-gap → Vertical gap.
  • column-gap → Horizontal gap.

2. Child (Flex Item) Properties

  • flex-grow → How much an item grows.
  • flex-shrink → How much an item shrinks.
  • flex-basis → Initial size before growing/shrinking.
  • flex → Shorthand: 
    flex: grow shrink basis;
    Examples: 
    flex: 1;
flex: 2;
flex: 1 1 auto;
flex: 0 0 200px;
  • align-self → Overrides align-items for one item.
    • auto
    • flex-start
    • flex-end
    • center
    • stretch
    • baseline
  • order → Changes visual order. 
    order: -1;
order: 1;
order: 999;

3. Most Common Patterns

Center Everything

display: flex;
justify-content: center;
align-items: center;

Even Space

justify-content: space-between;

Equal Width Columns

.item {
    flex: 1;
}

Fixed Sidebar + Flexible Content

.sidebar {
    flex: 0 0 250px;
}

.content {
    flex: 1;
}

Allow Wrapping

display: flex;
flex-wrap: wrap;
gap: 20px;

4. Axes Reminder

flex-direction: row;

Main Axis  → →
Cross Axis ↓

justify-content = Main Axis
align-items     = Cross Axis

flex-direction: column;

Main Axis  ↓
Cross Axis →

justify-content = Main Axis
align-items     = Cross Axis

5. Flex Shorthand Quick Reference

Value Meaning
flex: 1; Grow to fill available space.
flex: 0; Don't grow.
flex: auto; Grow and shrink automatically.
flex: none; Fixed size.
flex: 0 0 300px; Always 300px wide.

🔥 Remember:

  • display:flex → Creates a flex container.
  • justify-content → Main axis alignment.
  • align-items → Cross axis alignment.
  • gap → Space between items.
  • flex → Grow • Shrink • Basis.
  • order → Visual order.
  • align-self → Override one item's alignment.
  • Main axis changes with flex-direction.
