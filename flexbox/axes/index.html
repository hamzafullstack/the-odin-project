Axes in css.

Axes

The most confusing thing about flexbox is that it can work either horizontally or vertically, and some rules change a bit depending on which direction you are working with. The default direction for a flex container is horizontal, or row, but you can change the direction to vertical, or column

No matter which direction you’re using, you need to think of your flex-containers as having 2 axes: the main axis and the cross axis.

flex-direction: row puts the main axis horizontal (left-to-right), and column puts the main axis vertical (top-to-bottom).

default setting is row for the flex-direction. you change to column if you want.

Flex Direction - Key Notes

• flex-direction: row (default) → Items are arranged horizontally.

• flex-direction: column → Items are arranged vertically.

Why flex: 1 breaks with column:

• flex: 1 = flex: 1 1 0.

• flex-basis: 0 starts the size calculation from 0.

• Empty <div> elements have 0 height, so they collapse.

• The defined height is ignored because the flex basis starts from 0.

Fixes:

• Use flex: 1 1 auto; to respect the element's height.

• Or use flex-grow: 1;.

• Or set a fixed height on the parent container.

Important:

• In row, flex-basis controls width.

• In column, flex-basis controls height.

Why row usually works:

• Block elements naturally take 100% width.

• Their height depends on their content.

• Empty elements have 0 height, which causes collapsing in column.

Extra:

• flex-direction may behave differently in right-to-left or vertical writing systems.
