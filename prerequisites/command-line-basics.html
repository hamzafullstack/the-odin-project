Foundations – Command Line Basics

Overview

The command line (terminal) allows developers to interact directly with the operating system using text commands. It is an essential tool for web development because many developer tools, Git, Node.js, and servers are operated through the terminal.

Learning Objectives

1. Understand the Command Line

  • Know what a terminal is.
  • Understand why developers use it.
  • Learn how commands interact with the operating system.

2. Navigate the File System

  • Move between folders.
  • Check your current location.
  • Create and delete directories.

3. Manage Files

  • Create files.
  • Copy files.
  • Move or rename files.
  • Delete files safely.

Essential Commands

Command Purpose
pwd Show current directory.
ls List files and folders.
cd Change directory.
mkdir Create a new folder.
touch Create an empty file.
cp Copy files or folders.
mv Move or rename files.
rm Delete files.
clear Clear terminal screen.
man Open command manual.

Important Notes

  • Be careful with rm because deleted files usually cannot be recovered.
  • Read command documentation using man.
  • Practice commands regularly to build muscle memory.
  • The terminal is faster than graphical file management for many tasks.

Why Developers Use the Terminal

  • Faster workflow.
  • Works on remote servers.
  • Required for Git and Node.js.
  • Automates repetitive tasks.
  • Industry standard skill.
  • Available on Linux, macOS, and Windows.
