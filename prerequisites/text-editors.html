Foundations – Text Editors

Overview

A text editor is one of the most important tools for a developer. Unlike word processors (Microsoft Word, Google Docs), text editors are designed specifically for writing and editing source code.

Main Objectives

1. What is a Text Editor?

  • A program used to write plain text.
  • Ideal for programming languages.
  • Does not add formatting like bold or colors to the actual file.

2. Code Editors vs IDEs

  • Code Editor: Lightweight and focused on writing code.
  • IDE (Integrated Development Environment): Includes debugging, project management, testing tools, and more.
  • VS Code is a code editor that can become IDE-like using extensions.

3. Why VS Code?

  • Free and open source.
  • Fast and lightweight.
  • Huge extension marketplace.
  • Excellent Git integration.
  • Built-in terminal.
  • Supports almost every programming language.

4. Customize Your Editor

  • Install useful extensions.
  • Choose a comfortable theme.
  • Configure settings to improve productivity.
  • Learn keyboard shortcuts.

Essential VS Code Features

  • Syntax Highlighting
  • Auto Completion (IntelliSense)
  • Integrated Terminal
  • Git Integration
  • Extensions
  • Debugging Support
  • File Explorer
  • Search & Replace
  • Multi Cursor Editing
  • Command Palette

Recommended Extensions

Extension Purpose
Live Server Launch local development server.
Prettier Automatically format code.
ESLint Find JavaScript mistakes.
GitLens Enhance Git functionality.
Auto Rename Tag Rename HTML tags together.
Auto Close Tag Automatically close HTML tags.

Assignment Summary

1. Install VS Code

Download and install Visual Studio Code, the recommended code editor for The Odin Project.

2. Learn the Interface

Become familiar with the Activity Bar, Explorer, Terminal, Extensions panel, and Command Palette.

3. Install Recommended Extensions

Install helpful extensions such as Live Server and Prettier to improve your workflow.

4. Learn Keyboard Shortcuts

Practice common shortcuts to navigate and edit code faster.
