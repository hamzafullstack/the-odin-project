Foundations – Setting Up Git

Overview

Git is a Version Control System (VCS) used to track changes in your projects. GitHub is an online platform where Git repositories are stored, shared, and collaborated on.

Learning Objectives

Understand Git

  • Know what Git is.
  • Understand why version control is important.
  • Track changes to projects.

Understand GitHub

  • Create repositories.
  • Host projects online.
  • Collaborate with other developers.

Configure Git

  • Set username.
  • Set email address.
  • Choose main as the default branch.

Connect GitHub using SSH

  • Create SSH key pair.
  • Add public key to GitHub.
  • Authenticate without typing password every push.

Git Configuration

git config --global user.name "Your Name"

git config --global user.email your-email@example.com

git config --global init.defaultBranch main

Verify:

git config --get user.name

git config --get user.email

git config --global --list

SSH Key

SSH (Secure Shell) uses public-key cryptography to securely identify your computer without sending your password every time.

Key Purpose
Private Key Stored on your computer. Never share it.
Public Key (.pub) Upload to GitHub.

Generate SSH Key

ssh-keygen -t ed25519

During setup:

  • Press Enter for default location.
  • Passphrase is optional.
  • Press Enter twice if you don't want one.

Copy Public Key

cat ~/.ssh/id_ed25519.pub

Copy everything from ssh-ed25519 until the end of the line.

Add SSH Key to GitHub

  1. GitHub → Settings
  2. SSH and GPG Keys
  3. New SSH Key
  4. Title (Example: ThinkPad T480)
  5. Key Type → Authentication Key
  6. Paste Public Key

Test SSH Connection

ssh -T git@github.com

Expected Output:

Hi username!
You've successfully authenticated,
but GitHub does not provide shell access.

Important Notes

  • Never share your private key.
  • Only upload the .pub key.
  • SSH removes the need to type your password every push.
  • You can create different SSH keys for different computers.
