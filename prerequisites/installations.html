The Odin Project

Foundations – Installations

Overview

Before writing code, every developer needs a proper development environment. The Odin Project recommends using a Unix-based environment because most modern development tools are designed for Linux or macOS.

Main Objectives

1. Set Up a Development Environment

  • Prepare your computer for web development.
  • Install the required operating system if needed.
  • Avoid browser-only coding environments.

2. Use a Supported Operating System

  • ✅ macOS
  • ✅ Ubuntu (Official Flavors)
  • ✅ Virtual Machine (Recommended for Windows users)
  • ✅ Ubuntu Dual Boot
  • ✅ WSL2 (Advanced Users)
  • ✅ ChromeOS Linux Support

3. Use Google Chrome

  • Chrome is the officially supported browser.
  • Developer Tools are heavily used throughout the course.
  • Lessons and screenshots assume Chrome.

Why Linux?

  • Most developer tools are built for Unix systems.
  • Better compatibility.
  • Easier troubleshooting.
  • Large developer community.
  • Excellent performance.
  • Commonly used in professional environments.

Windows Users

The Odin Project does not support native Windows as a development environment. Windows users are encouraged to use one of the following:

  • Virtual Machine (Recommended)
  • Ubuntu Dual Boot
  • WSL2 (Advanced)

Installation Options

Method Recommended For
Virtual Machine Beginners (Best Choice)
Ubuntu Dual Boot Maximum Performance
WSL2 Advanced Windows Users
macOS Mac Users
ChromeOS Linux Chromebook Users

Assignment Summary

1. Choose Your Installation Method

If you're not already using a supported operating system, follow the installation guide that matches your computer.

2. Install Google Chrome

Download and install Google Chrome because all future lessons use Chrome Developer Tools.

3. Learn Chrome Shortcuts

Review common Chrome keyboard shortcuts to improve productivity during development.

Key Takeaway

A proper development environment is the first step toward becoming a professional developer. Spending time setting it up correctly now will save countless hours of troubleshooting later.
