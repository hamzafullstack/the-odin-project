Web fonts

web fonts are alternative to system fonts which works well, css allows you to specify font files, available on the web, to be downloaded along with your website as it's accessed. this means that any browser supporting this css feature can be display the fonts you've specifically chosen. 

@font-face {
  font-family: "myFont";
  src: url("myFont.woff2");
}

note: always keep in mind fonts generaly are not free all major browsers support woff/woff2 format
