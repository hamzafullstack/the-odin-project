What are default styles and where do they come from?

As you worked on projects you likely observed default styles applied to certain elements such as larger and bolder heading on h1 element and blue underlined links on "a" element. there is also a good chance you struggled with default margin and padding. these styles are part of the user-agent stylesheets, each browser has its own set of user-agent stylesheet.
