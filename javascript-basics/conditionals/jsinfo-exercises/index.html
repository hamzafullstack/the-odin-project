Exercise 1: if (a string with zero)

Description

if ("0") {
    alert("Hello");
}

اوپر دیا گیا کوڈ چلانے پر کیا alert ظاہر ہوگا یا نہیں؟

Exercise 2: The name of JavaScript

Description

if...else استعمال کرتے ہوئے ایسا پروگرام لکھیں جو صارف سے پوچھے:

What is the "official" name of JavaScript?

اگر صارف ECMAScript لکھے تو مناسب کامیابی کا پیغام دکھائیں، ورنہ دوسرا پیغام دکھائیں۔

Exercise 3: Show the sign

Description

prompt کے ذریعے ایک عدد حاصل کریں اور if...else استعمال کرتے ہوئے اس کی علامت معلوم کریں۔

  • اگر عدد صفر سے بڑا ہو۔
  • اگر عدد صفر سے چھوٹا ہو۔
  • اگر عدد صفر کے برابر ہو۔

فرض کریں کہ صارف ہمیشہ درست عدد ہی درج کرے گا۔

Exercise 4: Rewrite "if" into "?"

Description

دیے گئے if...else کو conditional (ternary) operator (?) استعمال کرتے ہوئے دوبارہ لکھیں۔

صرف کوڈ کو نئے انداز میں تبدیل کرنا ہے، اس کا نتیجہ تبدیل نہیں ہونا چاہیے۔

Exercise 5: Rewrite "if...else" into "?"

Description

متعدد conditional (ternary) operators (?) استعمال کرتے ہوئے دیے گئے if...else if...else کو دوبارہ لکھیں۔

کوڈ کو پڑھنے میں آسان رکھنے کے لیے اسے مناسب انداز میں متعدد لائنوں میں لکھیں۔
