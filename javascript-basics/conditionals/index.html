JavaScript Conditionals

Conditionals allow your program to make decisions based on whether a condition is true or false. They control the flow of execution, allowing different code to run under different circumstances.

Types of Conditionals

  • if
  • else
  • else if
  • switch
  • ternary operator ( ? : )

Common Use Cases

  • Login authentication
  • Age verification
  • Checking passwords
  • Displaying different UI elements
  • Form validation
  • Game logic
  • Role-based access (Admin/User)
  • Error handling

Example

let age = 20;

if (age >= 18) {
    console.log("Adult");
} else {
    console.log("Minor");
}

Facts

  • Every condition evaluates to either true or false.
  • JavaScript automatically converts values to boolean when needed (truthy/falsy).
  • switch is useful when comparing one variable against many fixed values.
  • The ternary operator is a shorter version of a simple if...else.
  • Conditionals can be nested inside one another.

Truthy Values

These behave like true:

true
1
-1
"Hello"
[]
{}
function(){}

Falsy Values

Only these values are falsy:

false
0
-0
0n
""
null
undefined
NaN

Tips & Tricks

  • Use === instead of == to avoid automatic type conversion.
  • Avoid deeply nested if statements; use else if, switch, or early return when possible.
  • Use meaningful variable names like isLoggedIn or hasPermission.
  • Use the ternary operator only for simple decisions.
  • Remember: = assigns a value, while === compares values and types.
Quick Memory Trick

if → One condition
else if → Multiple conditions
else → Default case
switch → Many fixed values
?: → Short one-line if...else
