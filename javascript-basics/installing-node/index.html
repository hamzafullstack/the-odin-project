Node.js Guide

What is Node.js?

Node.js is an open-source JavaScript runtime that allows you to run JavaScript outside the web browser. It is built on Google's V8 JavaScript engine and is commonly used for backend development, APIs, real-time applications, and command-line tools.

Common Uses

  • Build web servers and REST APIs.
  • Create real-time apps (chat, games, notifications).
  • Develop command-line (CLI) tools.
  • Run JavaScript programs outside the browser.
  • Manage project dependencies using npm.

Install on Windows

  1. Visit nodejs.org.
  2. Download the LTS version.
  3. Run the installer and complete the setup.
  4. Open Command Prompt and verify the installation.
node -v
npm -v

Install on Linux (Ubuntu/Debian)

  1. Update package lists.
  2. Install Node.js and npm.
  3. Verify the installation.
sudo apt update
sudo apt install nodejs npm -y

node -v
npm -v

Running JavaScript with Node.js (Windows)

  1. Create a file named app.js.
  2. Write your JavaScript code.
  3. Open Command Prompt or PowerShell.
  4. Navigate to the folder containing the file.
  5. Run the file using the node command.

Example: app.js

console.log("Hello, Node.js!");

Run the file:

cd path\to\your\folder
node app.js

Output:

Hello, Node.js!

Interesting Facts

  • Released in 2009 by Ryan Dahl.
  • Uses Google's V8 JavaScript engine.
  • Uses an event-driven, non-blocking architecture.
  • Includes npm, one of the world's largest package managers.
  • Runs on Windows, Linux, and macOS.
  • Popular companies using Node.js include Netflix, PayPal, LinkedIn, and Uber.
